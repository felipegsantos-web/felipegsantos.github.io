{%- comment -%} Structured data. Which blocks a page gets is set in its front matter: `jsonld: person` (homepages and CV pages): ProfilePage with the Person. `jsonld: publications` (publication lists), `theme:` (theme pages): a CollectionPage and one block per publication. `work:` (book page): the block of that publication. {%- endcomment -%} {%- if page.jsonld == "person" %} {%- include jsonld-person.html %} {%- elsif page.jsonld == "publications" or page.theme %} {%- if page.theme %}{% assign parts = site.data.publications | where_exp: "p", "p.themes contains page.theme" %}{% else %}{% assign parts = site.data.publications %}{% endif %} {%- for pub in parts %} {%- include jsonld-work.html pub=pub %} {%- endfor %} {%- elsif page.work %} {%- assign pub = site.data.publications | where: "id", page.work | first %} {%- include jsonld-work.html pub=pub %} {%- endif -%}
